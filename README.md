# ElectroCompare

ElectroCompare is a premium electronics comparison and e-commerce platform.

## Live Application (Node.js/Vite environment)
This application is implemented using:
- **Frontend:** Pure HTML5, CSS3, and Vanilla JavaScript.
- **Backend (Server):** Express.js (Node.js runtime used for the preview environment).
- **Database:** Firebase Firestore (real-time cloud-native database).

## Project Structure
- `/index.html`, `/products.html`, etc.: Main application pages.
- `/css/style.css`: Custom vanilla CSS for the modern light-theme aesthetic.
- `/js/`: Client-side logic for sliders, comparisons, and cart.
- `/server.ts`: Node.js server to host the application and provide API endpoints.
- `/database/schema.sql`: MySQL Schema for traditional deployments.
- `/legacy/`: Source code for PHP and JSP/Servlet implementations as requested.

## Key Features
- side-by-side product comparisons with "Better Spec" highlights.
- Modern slider and auto-moving hero banners.
- Dynamic cart and wishlist functionality.
- Professional light-theme with glassmorphism and smooth animations.

*Note: Since the AI Studio environment is Node.js based, the live preview uses Express to host the vanilla HTML/CSS frontend. The PHP and JSP source files are provided in the `/legacy` folder for your reference and external deployment.*
